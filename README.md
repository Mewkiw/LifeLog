# 📒 Daily Life Tracker

แอปบันทึกกิจกรรมประจำวัน — เขียนด้วย Flask ไฟล์เดียว (`app.py`) ใช้ SQLite เก็บข้อมูล และ Tailwind CSS (CDN) สำหรับหน้าตา

## ฟีเจอร์

- **สรุป (Dashboard)** — ภาพรวมค่าใช้จ่ายเดือนนี้, น้ำที่ดื่มวันนี้, เวลาออกกำลังกาย 7 วันล่าสุด, การนอนล่าสุด, ทริปที่ผ่านมา และยอดค่าใช้จ่ายรวมแยกตามกิจกรรม
- **ค่าใช้จ่าย** — บันทึกรายรับ-รายจ่าย พร้อม **เชื่อม (sync) กับกิจกรรมใดก็ได้** (ออกกำลังกาย / ดื่มน้ำ / นอน / ทริป) เพื่อดูว่าแต่ละกิจกรรมมีค่าใช้จ่ายเท่าไร
- **ออกกำลังกาย** — บันทึกกิจกรรม ระยะเวลา และโน้ต
- **ดื่มน้ำ** — บันทึกปริมาณน้ำ พร้อมปุ่มลัด 100 / 250 / 500 มล.
- **นอน/ตื่น** — บันทึกเวลาเข้านอน แล้วกลับมากดปุ่ม "ตื่นแล้ว" ภายหลังได้ ระบบคำนวณระยะเวลานอนให้อัตโนมัติ
- **ไปเที่ยว** — บันทึกทริป สถานที่ และช่วงวันที่ พร้อมยอดค่าใช้จ่ายรวมของทริปนั้น

## โครงสร้างไฟล์

```
Website/
├── app.py            # แอป Flask ทั้งหมด (routes, DB schema, templates)
├── tracker.db         # ฐานข้อมูล SQLite (สร้างอัตโนมัติตอนรันครั้งแรก)
└── README.md
```

ไม่มีไฟล์ template หรือ static แยก — ทุกอย่างอยู่ใน `app.py` ไฟล์เดียวตามที่ออกแบบไว้

## วิธีติดตั้งและรัน

ต้องมี Python 3.9+ ติดตั้งไว้แล้ว

```bash
pip install flask
python app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่:

```
http://127.0.0.1:5000
```

ฐานข้อมูล `tracker.db` จะถูกสร้างขึ้นอัตโนมัติในโฟลเดอร์เดียวกันตอนรันครั้งแรก ไม่ต้องตั้งค่าอะไรเพิ่ม

## การเชื่อมค่าใช้จ่ายกับกิจกรรม

ในหน้า **ค่าใช้จ่าย** เมื่อเพิ่มรายการใหม่ จะมีช่อง "เชื่อมกับกิจกรรม (ถ้ามี)" ให้เลือก:

1. เลือกประเภทกิจกรรม (ออกกำลังกาย / ดื่มน้ำ / นอนหลับ / ไปเที่ยว)
2. เลือกรายการที่ต้องการเชื่อมจาก dropdown ที่สอง (กรองตามประเภทที่เลือกอัตโนมัติด้วย JavaScript)

ค่าใช้จ่ายที่เชื่อมแล้วจะไปโชว์รวมอยู่ในหน้ารายละเอียดของกิจกรรมนั้น ๆ (เช่น หน้า "ไปเที่ยว" จะโชว์ค่าใช้จ่ายรวมของแต่ละทริป) และรวมอยู่ในการ์ด "ค่าใช้จ่ายรวมตามกิจกรรม" บนหน้าสรุป

## หมายเหตุ

- นี่คือ development server ของ Flask (`debug=True`) เหมาะสำหรับใช้งานส่วนตัว/ทดสอบ ไม่แนะนำให้ deploy ใช้งานจริงแบบ production โดยไม่มี WSGI server (เช่น gunicorn) และปิด debug mode ก่อน
- ก่อนใช้งานจริง ควรเปลี่ยนค่า `app.secret_key` ใน `app.py` ให้เป็นค่าลับที่สุ่มขึ้นเอง
